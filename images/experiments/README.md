# Temporary experiment artwork

Generated using the built-in image generation tool for the approved site concept. These are illustrative thumbnails, not screenshots of running systems.

- `lucy.webp`: a silver neural machine with interconnected nodes on a near-black field.

Shared prompt constraints: minimal monochrome editorial landscape, restrained scientific model photography, no text, logo, or color. Original generation files remain in Codex generated_images; site assets are resized WebP copies.
